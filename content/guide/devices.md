По умолчанию группа работает для всех устройств домашней сети. Её можно ограничить: например, пустить YouTube через туннель только на телевизоре и детских планшетах, а остальным оставить прямой путь.

Выбор открывает кнопка устройств в строке группы. На ней написано, для кого сейчас работает группа: **Все устройства**, число выбранных устройств или «Все, кроме …». То же поле **Устройства** есть в окне **Настройки группы**.

![Окно «Устройства»: группа работает только для политики Kids](/img/ui/devices.png)

## Два режима

- **Для всех устройств** — группа работает для всех, кроме тех, кого вы выключите. Новые устройства, которые появятся в сети потом, группа тоже будет обслуживать.
- **Только для выбранных** — группа работает только для тех, кого вы включите. Новые устройства в неё не попадут, пока вы их не включите.

Совсем пустой выбор сохранить нельзя: в режиме **Только для выбранных** включите хотя бы одно устройство или политику. Чтобы группа не работала ни для кого, выключите её переключателем на странице групп.

## Политики

В блоке **Политики** перечислены политики доступа Keenetic — группы устройств, которые вы завели в самой прошивке, — и сколько в каждой устройств. Включённая политика означает «устройства, которые сейчас в этой политике». Если в прошивке перенести устройство в другую политику, firc это учтёт сам, менять группу не нужно.

Если на роутере нет ни одной политики, блок так и скажет: **На этом роутере нет политик.**

## Устройства из списка роутера

Ниже — устройства, которые знает роутер: имя, точка «в сети» или «не в сети», IP-адрес и MAC. Есть поиск по имени, IP или MAC. Справа над списком написано, для скольких устройств сейчас работает группа.

Под именем устройства firc объясняет, почему оно включено или выключено: **включено через политику Kids**, **включено ручной записью**, **выключено политикой …** и так далее.

Устройство запоминается по MAC: если роутер выдаст ему по DHCP другой адрес, выбор не сбросится.

## Вручную

Блок **Вручную** нужен для того, чего нет в списке роутера: устройств с постоянным адресом, целых подсетей. По одной записи в строке, адрес или префикс CIDR:

- **Разрешить ещё** — добавить к группе;
- **Запретить** — исключить из группы.

![Блок «Вручную»: подсеть разрешена, один адрес запрещён](/img/ui/devices-manual.png)

Если роутер не прислал ни одного устройства, firc предложит добавить адреса и префиксы вручную.

## Что значит «группа не работает для устройства»

Для устройства, которому группа не положена, она как будто выключена. Его DNS-запросы получают обычный ответ, а трафик идёт напрямую через основной интернет, мимо интерфейса группы. Это не блокировка: если сайт закрыт у провайдера, напрямую он не откроется.

Выбор устройств действует на все правила группы: на домены, на правила из [списка](../lists/) и на подсети.

{{< callout type="warning" >}}
Изменение действует не сразу. Устройство, которое уже спрашивало домен группы, хранит в своём DNS-кэше адрес, выданный firc, до 5 минут (это **Потолок TTL** в [настройках](../settings/)). Пока кэш не истечёт, такой сайт на только что запрещённом устройстве не откроется: firc не пускает свои адреса мимо группы. В обратную сторону так же: только что разрешённое устройство ходит напрямую, пока не истечёт старый ответ. Ускорить можно, сбросив DNS-кэш устройства или перезапустив браузер.
{{< /callout >}}

Это же объяснение есть в самом окне, под значком рядом с заголовком **Устройства**.

Один и тот же домен можно отдать разным группам для разных устройств. Как firc выбирает группу в этом случае, описано в разделе [Порядок групп](../groups/#порядок-групп).
