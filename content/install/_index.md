firc ставится на роутер Keenetic пакетом Entware. Понадобятся Entware, доступ к роутеру по SSH и пара минут.

## Что нужно

- Роутер **Keenetic** с установленным **Entware** и KeeneticOS 4.3 или новее. 
- Одна из архитектур: **aarch64** (MT7622, MT7981, MT7988), **mipsel** (MT7621, MT7628) или **mips** (EN7512/EN7516).
- Около **10 МБ** на накопителе Entware при установке с нуля (сам firc — около 2,4 МБ, остальное — `curl` и OpenSSL, если их ещё нет) и около **1 МБ** под самообновление.
- firc использует около 5 МБ ОЗУ без правил и около 21 МБ ОЗУ при 300 000 правил в списках.

{{< callout type="info" >}}
Entware ещё не стоит? Включите компонент **OPKG** (веб-интерфейс роутера → **Управление** → **Настройки системы** → **Изменить набор компонентов**) и следуйте [справке Keenetic](https://help.keenetic.com/hc/ru/articles/360021214160). Накопитель должен быть в **ext4**.
{{< /callout >}}

## Подключитесь по SSH

Подключитесь к Entware: `ssh root@192.168.1.1 -p 222` (порт `22`, если на роутере нет компонента «SSH-сервер»). Пароль Entware по умолчанию — `keenetic`.

{{< callout type="warning" >}}
Смените пароль командой `passwd` сразу после первого входа. Этим же паролем вы будете входить в веб-интерфейс firc.
{{< /callout >}}

## Установите firc

Узнайте архитектуру: `opkg print-architecture`. Строка с `_kn` подскажет имя репозитория:

- `aarch64-3.10_kn` → `aarch64-k3.10`
- `mipsel-3.4_kn` → `mipsel-k3.4`
- `mips-3.4_kn` → `mips-k3.4`

Подключите репозиторий и поставьте пакет (пример для mipsel; для другой архитектуры замените `mipsel-k3.4` на имя своего репозитория):

```shell
grep -qs repo.hoaxisr.ru /opt/etc/opkg.conf /opt/etc/opkg/*.conf ||
  echo "src/gz hoaxisr http://repo.hoaxisr.ru/mipsel-k3.4" > /opt/etc/opkg/hoaxisr.conf
opkg update && opkg install firc
```

Первая строка добавляет репозиторий, только если его ещё нет. В конце установки firc сам запускается и выводит адрес веб-интерфейса:

```
firc: WebUI at http://192.168.1.1:666
```

> [!TIP]
> Если репозиторий repo.hoaxisr.ru у вас уже добавлен, достаточно выполнить:
>
> ```shell
> opkg update && opkg install firc
> ```

{{< callout type="info" >}}
Пакеты для ручной установки лежат на странице [Releases](https://github.com/hoaxisr/firc/releases). Качайте с `curl -L`.
{{< /callout >}}

## Первый вход

Откройте адрес из вывода установки, обычно `http://192.168.1.1:666`. Войдите с учётными данными **Entware**: логин `root` и пароль, который вы задали `passwd` (по умолчанию `keenetic`).

Если порт 666 занят другой программой, firc выберет следующий свободный из 999, 1666, 2666, 9999, запомнит его и напечатает при установке. Поменять порт можно в [настройках](../guide/settings/).

Дальше — [Быстрый старт](../quickstart/): первая группа и проверка, что всё работает.

## Обновление

Проще всего — из веб-интерфейса: firc сам проверяет новые версии и предлагает обновиться (подробнее в разделе [Обновление](../guide/update/)). Из SSH (если был добавлен репозиторий):

```shell
opkg update && opkg upgrade firc
```

Настройки и группы при обновлении сохраняются.

## Удаление

```shell
opkg remove firc
```

firc убирает за собой правила и маршруты, удаляет кэш подписок и свой токен доступа к роутеру. Файлы `/opt/etc/firc/firc.conf` и `/opt/etc/firc/groups.yaml`, если вы их меняли, `opkg` оставляет на месте — при повторной установке firc их подхватит. Чтобы удалить и их, сотрите каталог `/opt/etc/firc` вручную.
